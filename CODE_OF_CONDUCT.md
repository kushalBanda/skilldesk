# Code of conduct

SkillDesk follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, and keep criticism about the code. Harassment, insults, and personal attacks aren't welcome in issues, pull requests, discussions, or anywhere else the project lives.

## Reporting

If someone's behavior makes you uncomfortable, tell the maintainer privately through GitHub: use **Report a vulnerability** on the [Security tab](https://github.com/kushalBanda/skilldesk/security) and say it's a conduct report, or use GitHub's **Report content** option on the comment. Reports stay confidential.

The maintainer may edit or remove comments, close threads, or block anyone who breaks this code, following the Covenant's enforcement guidelines.
